PortalAsylumAdminScript - Installation Guide
==========================================

Option A - Rojo sync (recommended, 1 command):
  1. Install Rojo: https://rojo.space
  2. Run "rojo serve" inside this extracted folder
  3. In Roblox Studio: open the Rojo plugin and click Connect
  4. All scripts sync automatically into the correct services

Option B - Manual copy (no tools needed):
  1. Open your game in Roblox Studio
  2. Files under ServerScriptService/ -> create a Script in ServerScriptService and paste the code
  3. Files under StarterPlayer/StarterPlayerScripts/ -> create a LocalScript there and paste the code
  4. Files under ReplicatedStorage/ -> create ModuleScripts with the same names
  5. Naming convention: *.server.luau = Script, *.client.luau = LocalScript, *.luau = ModuleScript
